# Fluid reference data

## Hydraulic references

`hydraulic-friction.json` is generated by `examples/Generate-Hydraulic-References.py` using Python Decimal at 60-digit precision, without production Java calls. It specifies Poiseuille friction below Reynolds 2,000, the project's cubic smoothstep blend from 2,000 to 4,000, and Swamee-Jain above 4,000. The latter relation is documented in [EPA EPANET 2.2 section 12](https://usepa.github.io/EPANET2.2/12_analysis_algorithms.html). The project blend is not EPANET's transition interpolation. Implicit Colebrook factors are separately bisected for turbulent points and retained as empirical-correlation comparisons, not an alternative numerical acceptance tolerance. Regeneration should produce an identical file.

## Water vapour and nitrogen references

`water-vapor-compression.json` (at the points of `water-vapor-checks.json`) is built by `examples/Fetch-FluidSteamReferences.py`, and `nitrogen-cp-checks.json` by `examples/Build-NitrogenFluidProperties.py`, from NIST Chemistry WebBook thermophysical fluid data (not generated by the production implementation). The raw NIST downloads (`steam-*.tsv`, `nitrogen-*.tsv`) are not tracked: both scripts use this folder as their download cache and fetch a missing file again. The copies taken by the code-consolidation batch (2026-10-15) are in the main checkout's `research/2026-10-15-code-consolidation/fluid-reference-tsv/`.
