# phase-ports-probes/hold-classes

The hold classes of the placement-sequence fuzz (`../hold-fuzz/`), worked through one by one: batch `documentation/2026-09-26-phase-ports-and-compressor/`, 2026-09-27, branch `claude/phase-ports-compressor` from `b3c44ed0`. Review sections: `PHASE_PORTS_REVIEW.md` "Hold class ..." (one per class) and "Holds F7 and the trace family" (the orchestrator's `t01`/`t02` runs made with these scripts). Nothing here is run by a Gradle task; the gate tests of implemented fixes live in `src/test`.

## Scripts (from the worktree root, one Gradle invocation at a time, JDK 21.0.11 set inside)

- `campaign.sh logs/NN-tag [seeds]`: seeds 1-1000 of the fuzz in both distributions (random, world defaults), 8 workers, classified with `../hold-fuzz/classify.sh` (`<prefix>-random-report.txt`, `-defaults-report.txt`, `.classes.txt`).
- `compare.sh <A-report> <B-report>`: seeds clean in A and not in B (worse) and the number cleared.
- `gates.sh logs/NN-tag [gametest-run-id]`: G1 fluid suites (+ `../holds3/summarize.sh`: count, junction lines against `../holds/12-junction-lines.txt`, MIXED_GAS_COST), G2 exact regression, G3 adjacent selection, G5 fluid GameTests when a run id is given.
- `hold-classes.init.gradle`: attaches `src/` and `../hold-fuzz/src/` to the test source set for one invocation (probes; `-Pinstr=...` forwarded as a system property).

## src/

- `E3ProbeTest.java`: reductions of fuzz seed 30 (class E3).
- `instr-*.patch`: instrumentation, never commit; `git apply` it, run, `git apply -R`.

## logs/

`x01`-`x07` class X (review "Hold class X"); `t01`, `t02` the orchestrator's gates and campaign on `f80def43`; later prefixes per class as cited in the review.

`logs/` is matched by the repository's `logs/` ignore rule: force-add it (`git add -f`).
