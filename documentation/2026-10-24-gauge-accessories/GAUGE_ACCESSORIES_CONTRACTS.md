# Instrument accessory contracts

Feature branch `codex/gauge-accessories`, base `1ba146c4`. Fresh worlds only. Fluid checkpoint **18**, storage-unit **11** and process protocol **fluid-14** are unchanged.

## Items and configuration

`pressure_gauge` and `temperature_gauge` stack to 64 with identical components; `accessory_wrench` stacks to one, without durability. No recipes. `GaugeSettings` uses validated persistent/NBT and inventory stream codecs. Canonical endpoints are absolute pascals/kelvin; defaults 101325–1101325 Pa displayed as 0–10 bar(g), and 273.15–473.15 K displayed as 0–200 °C. Pressure units Pa/kPa/bar/MPa and absolute/atmospheric-relative reference; temperature °C/K. Atmospheric reference is 101325 Pa. Finite non-negative SI endpoints and a finite positive span are mandatory. Scale limits never constrain a process.

`GaugeMenu` binds the exact stack object, hand, selected main-hand slot and original component. `GaugeScreen` reuses the fluid GUI NumericDraft to preserve untouched SI bits across unit/reference changes. Shift-use opens in air or at a block, Enter sends Save, Escape cancels; incomplete/invalid values disable Save. The server checks menu ID/lifetime, stack binding and kind. The settings protocol is part of instruments-1, independent of fluid menu publications.

## Hosts, slots and hit geometry

`AccessoryHost` exposes static InstrumentMetadata; `InstrumentHosts.Host`, `InstrumentMount`, `AccessorySelection` and `PipeAccessoryMount` share transforms/bounds between previews, drawing, hover and server validation. The loaded-host index is guarded between integrated client/server threads; world reads occur after taking a position snapshot. An installed-only index avoids visiting ordinary pipe geometry for idle instrument rendering/watch selection.

Stable reservoir slots: vertical drums pressure_top, pressure_bottom, temperature_bottom; floating-roof tanks pressure_bottom, temperature_bottom; spheres pressure_top, temperature_top. InstrumentSockets uses the native design axis, front heading and shell surface. Taps are separate from fluid nozzles. Native integral level indicators remain untouched. Dial housings are 0.30 m; pipe stems follow the actual pipe outside diameter. Straight/end/isolated sections provide upright horizontal lateral sockets pipe_north/south/east/west; corners/junctions are rejected. One gauge, sight glass or valve occupies a pipe in total. Gauges never lock pipe connections; an invalidated socket refunds the configured gauge once.

Owner refinement, 2026-10-25: placement ghosts and accessory outlines are shown only on constructed equipment; pipes remain installable and expose exact-value hover without highlights. Held gauges show equipment sockets within 8 m: faint native steel/pale-face previews (alpha56 idle,88 aimed), with a thin circular accent ring (alpha135), muted blue/green/red for idle/reachable/blocked. No bright filled tint or bounding-box highlight. Occupied/blocked sockets use only the ring, avoiding coincident ghost/model faces. Wrench selection includes native valve/sight-glass model bounds, including overhanging actuators/handles. Reach and occlusion use those same extents; no extra fluid storage, collision or solver node is created.

## Lifecycle and storage

AccessoryStore is overworld SavedData `icheme_accessories`, **format 1**, keyed by globally stable fluid identity plus mount ID. It stores configured gauge kind/settings, UUID instance and revision; existing pipe fittings also have persisted UUID/type/revision. Host revision tombstones survive removal. Pending events persist request/player UUIDs, target dimension/position, instance, expected host revision, action/type/settings, hand/slot and the next online-time deadline. Reads reject malformed versions, lists, settings, identities, roles, duplicates and revisions.

Server-thread InstrumentService accepts vanilla item actions and commits them on online-time 100-tick deadlines. It revalidates held item, host, slot revision, reach/occlusion and permissions before consuming/transferring items. Duplicate or invalidated requests have no further effect. Survival consumes one gauge, creative consumes none. Shift-wrench returns one item to inventory, dropping the remainder if full. Breaking/dismantling and invalidation use the same registry removal/refund path; pipe loot now drops only its body. Creative breaking suppresses refunds.

Valve removal uses PhysicalRegistry.removePipeAccessory on the latest projected registration. It preserves identity, geometry/spec and unrelated pending edits, changes control to Passive and cutoff to NONE, and rebuilds ordinary mechanical neighbor connections. No menu open/load/input handler forces a solve. Native refresh retains stable IDs/slot names and recomputes transforms; a moved reservoir datum is queued under the same ID with authoritative inventory retained. Nothing replaces another block.

## Readings and network

PipeObservation captures the accepted solver row on its worker, including native drawn-stream viscosity/density, section losses, port/control heads, endpoint pressures/elevations and carried-fluid donor temperature. Physical View adds an ephemeral tap location; two-actuator runs select the proper half. Observation reverses section traversal as needed without changing the solver's section order or equations. Local pressure subtracts the actual cumulative section-loss share and hydrostatic column at the section's registered hydraulic datum. Dead-end/pruned/disconnected pipes have no observational mapping and show pressure unavailable. Rest reductions preserve connected static pressure; solid-event results and certificate replay retain observation records. Readings are ephemeral and are not added to checkpoint/unit/process payloads.

Reservoir samples reuse published Tank top/bottom pressures and bulk temperature; bottom head remains the native condensed-mass head. Pipe temperature uses accepted carried fluid, retaining the last valid temperature as stale/no-flow when flow stops; unavailable before the first valid reading. Source sample ticks remain distinct from publication time. Hover shows exact formatted value, reference, configured range, availability/age and out-of-range status; only the needle clamps. Cached housing/tick geometry stays fixed; needle angle follows publications.

InstrumentNetwork **instruments-1** watches identify root position, host/mount and accessory UUID. Client requests the nearest 64 installed instruments within 120 m; server validates loaded host, current instance, dimension and a 128 m bound. New watches replay cached samples without solving/applying input. Observed hosts publish on existing staggered approximately 5-second engine buckets. Removal/unload/range/dimension/disconnect release watches/caches. Ordinary BE updates carry static settings/model metadata only.
