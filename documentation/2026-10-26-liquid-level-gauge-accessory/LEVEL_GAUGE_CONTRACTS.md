# Liquid-level gauge contracts

Snapshot `b1477c09`, 2026-10-26, base `600549d9` (0.13.2). No automatic merge or version bump.

- `icheme:liquid_level_gauge`: stack64, creative Functional Blocks/commands, no recipe/settings component/menu. Both hands use `LiquidLevelGaugeItem` and the shared `InstrumentService.request` transaction. Only constructed floating-roof tanks offer the fixed full-height `tank_level` mount.
- `Instrument.Type.LEVEL_GAUGE` uses immutable `Instrument.Fitting` (key, instance, revision, type). It reuses the existing store's non-dial fitting records, whose type determines `tank_level` versus `pipe_accessory`. Pressure/temperature gauges may coexist with the tank fitting; pipe fittings remain exclusive. No new facts-record field, schema, state format or migration.
- `Store.Pending` validates the item class/slot/type combination; `installFitting` requires the accepted matching queued request and revision. Server commit revalidates held stack/hand, identity, slot, permission, reach and clearance before survival consumption. Duplicate/invalid/replayed requests consume nothing. Creative installation consumes nothing.
- Metadata adds the optional static fitting record to the host's ordinary save/update copy. `bind` restores it from the authority; client receipt updates the loaded-host index. The field carries no level, composition or process inventory. Removing it from a reused tag explicitly clears the old field.
- Wrench removal shares the existing fitting path, returns one item to inventory (drop if full), and advances the tombstone revision. Host break/dismantling uses the same record removal, so repeated callbacks cannot refund again. Unsupported rebinds recover once. Native refresh keeps host identity/logical slot and recomputes geometry from the new shape.
- `TankDesign` no longer draws the indicator in its fixed mesh. `ShapeRasterizer.tankGauge(shape)` returns immutable cached accessory polygons for supported tanks. `TankGaugeGeometry.bounds` supplies the dedicated server's transformed geometry bounds without building surfaces. The clearance/reach box does not extend below grade, so its drain can touch a foundation.
- `InstrumentHosts.LevelGauge` supplies the selection/clearance/ghost extent. The host index considers long gauge bounds, permitting selection near either end and in the middle. Ghosts are restrained cyan/green/red and only show while holding the item; pipes and other reservoirs offer none.
- `TankRenderer` caches the fixed metal as another native VBO part; it draws only for installed metadata. Liquid bands/float remain before terrain translucency; the removable clear sleeve draws after its contents. Existing custom glass/continuous UVs, scale marks, water/oil colours and full-height connections remain.
- Readings reuse the tank's existing requested `TankDisplay` cache/glide and publication schedule. There is no new live payload, solver node, inventory, flash, operating limit or forced update. Hover shows only published/interpolated liquid height in metres, or unavailable.
