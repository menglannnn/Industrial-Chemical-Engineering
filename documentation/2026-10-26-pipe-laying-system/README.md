# 2026-10-26-pipe-laying-system

Purpose: Owner request 2026-10-26: design a pipe laying system. It has four parts: a pipeline tool that lays a routed line between two clicks, with a ghost, cancel and dismantle; a pipe rack block that holds up to five lines, each visible from all sides; highlighted equipment ports while the tool is held; and off-centre pipe connections at equipment that re-centre once they leave the constrained zone. It must fit the backward-compatibility design.

Status: Implemented 2026-10-27: merged to `main` as 0.14.0 (fast-forward to `4a7c807b`), not pushed. W1 to W4, the remaining plan items, the line paint, the layered rack (R1-R4), the junction model, the sturdy frame, the rack flanges, placement by facing, the slot aim, the second-click fix, one-block rack lines and their client update, and the code consolidation are committed on branch `claude/pipe-laying-system-092ac8` (worktree `wonderful-banach-1f1152`, release prep `4a7c807b`). The layered rack passed its in-game check; the owner waived the final lane. Merge preparation (W5): `MERGE_REVIEW.md`. Index: [../INDEX.md](../INDEX.md).
