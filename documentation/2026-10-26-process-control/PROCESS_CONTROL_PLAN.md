# Approved process-control implementation plan
Owner approval: 2026-10-27; batch folder reserved 2026-10-26. Two batches: implement sensors/local control and vessel physics now; define cables/remote level contracts now and implement them later.

## First-batch acceptance
- Pressure/temperature probes: pipelines and floating-roof tank, sphere, vertical/horizontal drums; pressure modules measure the valve upstream tap. Flowmeter: pipeline or valve module, signed mass and actual local-volume flow. Digital level: vessel body plus a separate horizontal-boot water-interface mount.
- Physical housings/placement ghosts, GUI readings only. Preserve analog/mechanical gauges and existing shared instrument sockets; one occupant per socket. Ordinary pipe one-accessory limit, explicit one P-or-flow module exception on a valve.
- Immutable sensor identity/measurement and controller/geometry/outlet contracts. Persistent host/mount/instance UUID/configuration revision; samples carry SI units, accepted simulation time and availability. Missing is unavailable, accepted empty level and stopped connected flow are zero; raw overrange is explicit.
- Reuse scheduled accessory admission/revalidation/removal and exactly-once recovery. Opening a GUI only replays cached publication and subscribes; closing unsubscribes. No process advancement/input application/solver on GUI open or per block tick.
- Shared cumulative V(h) and inverse for cylinder, sphere, vertical/horizontal drums with 2:1 heads and boots. Use for level, hydrostatic head, weir thresholds and later level control. Preserve capacities, nozzle positions, contents, components, energy and slurry/solids accounting.
- Body datum = body bottom; boot-interface datum = boot bottom. Percentage = height/span, not volume percentage. Accepted empty vessel reads zero; do not clamp telemetry before control.
- Ordinary bottom: equal HC/water volume rates while both exist, then remaining liquid, then gas. Boot drain: water, HC, gas. Boot HC outlet: HC, then water above the body D/3 weir, then gas at/below the weir. Weir retained volume includes boot volume below the body. Retain other top/side/overflow rules.
- Shared draw result drives hydraulic density, velocity/phase caps, reconstruction and displayed transfers. Treat depletion and weir crossing as solve transitions; jointly account for arrivals and competing drains, and conservatively solve the boundary water/gas split.
- Existing pressure-control-valve ID becomes visible Control Valve. Bare is fully open / “Lacking components”. A pressure module selects upstream absolute-pressure regulation; a flow module selects mass/actual-volume control. Reject an extra control source. Defaults: 200 kPa absolute and .01 m³/s actual.
- Ideal regulation, no PID/tuning/actuator delay. Forward active control, no pump behaviour or added shaft work. Solve upstream pressure/flux target with fluid equations and REGULATING/FULLY_OPEN/CLOSED limits; unreachable targets report limited control without holding the island.
- Actuator unknown = throttling head. Effective local-bore opening obeys Δp = rho*v²/2*(u^-2 - 1); u=1 adds no restriction and u=0 closes exactly. Use the same characteristic for held openings.
- Read trial state, carry accepted regimes with source/target/revision validity, extend rate/startup/certificate paths, solve independent loops jointly, and detect dependent/incompatible rows with affected-loop status and last accepted opening fallback. Preserve unrelated diagnostics.
- Separate saved installation/configuration facts from disposable samples/openings/regimes/caches. Keep registry IDs or aliases. Convert placed legacy pressure valves once into valve-plus-probe, retaining target; removing that probe never recreates it. Add changed-facts corpus images, rebuild incompatible state, retain unloaded registration geometry and queue legacy reconciliation without chunk forcing.

## Later cable batch
- Separate pipe-style block-grid graph: one unbranched component joins exactly one sensor and one valve; reject branches/fan-out/extra endpoints/local-plus-remote source.
- Initial remote level meters stay within the same fluid island; body and boot meters may each control their own independent valve. Registration survives unload without force-loading endpoints.
- Height or height-percent target; default 50%, Outlet action (open on high level), selectable Inlet action (open on low level). Coupled end-of-step geometry-derived inventory target; stationary rate/startup behaviour, never a constant transient level-error equation.
- Broken/invalid link holds last accepted opening, or fully open if none. Source identity reaches the solver independently of GUI publication. Test both actions, independent body/boot loops, conflicts/disconnection/unloading and step-size chatter. Detailed interface: DATA_SYSTEM_CONTRACT.md and ControlBinding.
