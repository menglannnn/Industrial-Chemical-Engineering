# 2026-10-26-multi-machine-framework

Purpose: Owner request 2026-10-26: design a multi-machine framework that combines several pieces of equipment into one structure, starting with the distillation column. The player designs the column in the calculator, selects its components there and saves the design; the constructor builds the column from it. The column GUI draws every component of the design, missing ones red and misplaced ones yellow, with the ports in the pipeline tool's colours. A player-triggered "Validate structure" walks the pipes from the column and binds what it finds. A fully validated structure opens the full GUI; a break returns it to its initial state without periodic checks. This stage is the structure only; the column's operation is the next stage.

Status: Implemented 2026-10-27 (0.15.0, main fast-forwarded to `ce71b45c`, not pushed).
